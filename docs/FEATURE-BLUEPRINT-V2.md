# WeightedPaths V2 设计蓝图：增强决策信息密度

> **核心哲学（用户 2026-08-09 定稿）**：
> 辅助与"外挂"之间只有一线之隔。一个好的辅助 Mod，应**增强玩家决策所需的信息密度**，
> 而**不是替玩家做决策**。
>
> **反例（现有 V1 的问题）**：给卡奖打 S/A/B 分 + 一条"推荐"，本质是"替玩家决策：你抓这个"。
> 玩家不信它（因为从没被真实对局证明过有效），于是觉得"一个都没解决"。
> 正确做法是把决策所需的料摆到玩家面前，让玩家自己拍板。

---

## 三个层级（用户原述"四层"，本蓝图先落地前三层）

### 第一层：基础信息透视（消除记忆负担）
这类游戏最大的门槛是"信息黑箱"，先解决"记不住"。

| 功能 | 说明 | 可行性 |
|------|------|--------|
| 路线节点预览增强 | 悬停地图下一层节点，显示具体怪物类型/事件池选项概率/商店基础折扣 | ⚠️ 部分可行（MTS UI 补丁，需地图/事件池数据） |
| **抓牌历史** | 选牌界面显示卡组已有同名牌数 | ✅ **已实现（2026-08-09）**：`CardRewardRenderPatch` 渲染"已有 N 张" |
| ~~牌池回溯/剩余深度~~ | ~~显示该稀有度剩余牌池深度~~ | ❌ **机制上不成立，已砍**：反编译验证卡池为**放回制**（`returnTrulyRandomCardFromAvailable` L996 从不移除已选卡），同张卡可反复出现，**没有"剩余深度"**。拿不拿过渡牌不影响后续核心牌概率（概率独立） |
| 敌方意图数字精确化 | 怪物下一击精确伤害（含力量/脆弱修正） | ⚠️ 部分可行 |
| 战斗预计回合数概率分布 | 基于卡组均伤估算战斗长度 | ❌ 几乎不可行（需完整战斗模拟引擎） |

### 第二层：动态价值评估（辅助抓牌核心）
不能简单给牌打 S/A/B（肉鸽里那是骗人的），应做"上下文评分"。

| 功能 | 说明 | 可行性 |
|------|------|--------|
| 卡组协同度雷达图 | 光标移向候选牌，实时算加入后对"输出峰值/启动速度/防御续航/过牌效率"四维的边际增量（delta） | ⚠️ 方向对；四维准确定量需战斗模型，现为经验近似 |
| 路线适应性推演 | 结合规划路线，估这张牌降多少战损（如"AOE 使精英战损 28→12"） | ⚠️ 精确值不可行，粗估区间可行 |
| 移除/敲位建议 | 火堆/商店高亮与核心体系协同最弱的牌 + 移除后抽牌期望提升 % | ✅ 现有 `removalUrgency`（污染层）可强化 |

### 第三层：路线规划沙盘（动态风险对冲）
辅助不应只推荐最佳路径，而应提供风险可视化。

| 功能 | 说明 | 可行性 |
|------|------|--------|
| 血量/资源走廊预测 | 每条路径标注预计残血区间（绿/黄/红暴毙），给出"不拿这张牌须多休息；拿了可多打一个精英"的替换连线 | ⚠️ 现有动态路线（低血保火堆）可增强 |
| Boss 对策匹配度 | 显示当前 Boss，标记本局卡组对 Boss 特定机制的抗性 | ✅ 可行（Boss 数据可拿） |
| 遗物联动预埋 | 抓牌时显示"本牌 + 某遗物形成 Combo" | ✅ 可行（现有遗物端口加成可扩展） |

## 与现有 V1 的关系

V1 的核心资产可复用，但定位要转向：
- 三端口（DAMAGE/BLOCK/ENGINE）+ 组件一致性 + 动态路线：**保留**，它们是正确的"信息评估框架"
- S/A/B/C 评分 + 硬推荐：**降级**为"参考信息"，不再作为唯一输出
- `removalUrgency`（污染层）、遗物端口加成：**保留**，作为第二/三层的地基

## 落地顺序（务实，从可行性最高做起）

1. **第一层·抓牌历史 + 牌池深度**（省力、立竿见影、天生"给信息不给结论"）
2. 第一层·路线节点预览增强（UI 补丁）
3. 第二层·移除/敲位建议强化
4. 第三层·Boss 对策 + 遗物联动
5. 幻想部分（战斗回合数概率分布、精确战损）**诚实砍掉，不画饼**

## 验证闭环（贯穿始终）

任何"评估"都要用真实数据证明有效，否则回到"拍脑袋系数"老路：
- 决策日志（`~/RunAdvisorLogs/run_*.json`，`enableDecisionLog` 默认 true）必须真正跑起来
- 用 `scripts/analyze_runs.py` 分析：推荐卡抓了胜率涨没涨、推荐路线是否避开暴毙
- 用真实数据反过来调系数，形成"猜系数 → 实测 → 调系数"闭环
