# 进游戏实测清单（1.5.0 · 8.11 交付版）

> 用途：CI/单测够不到 patch/UI/时序层，本清单用一轮真实对局验证「接入之后」的主链路。
> 每步记录：操作 → 预期现象 → 实际现象 → 结论（通过/失败/备注），失败时附日志片段。

## 准备

- 游戏 + ModTheSpire 3.26+ + BaseMod 5.39+；mod 用 `target/WeightedPaths.jar`（`mvn package` 产物）放入 mods 目录。
- 可选：配置 DeepSeek key（环境变量或系统属性，见 `DeepSeekClient`）。有 key 测 AI 链路，无 key 测兜底链路——两条都要测。
- 日志目录：`~/RunAdvisorLogs`（本机即 `C:\Users\Administrator\RunAdvisorLogs`）：
  - `run_state.json`：本局状态（SL 恢复依据，含 pact 字段）
  - `player_relation.json`：跨局关系档案
  - `agent_log.json`：AI 决策日志（含 tools/fellback/latencyMs）
  - `run_*.json`：每局决策回放
- 建议先备份日志目录，测完一轮后跑 `scripts/eval_card_recommendations.py` 出报告。
